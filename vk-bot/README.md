# VK-бот для Вегетария АСХТ

Этот проект содержит VK-бота на Node.js, который собирает заказы на растения через диалог в VK и сохраняет их в MongoDB.

## Установка

1. Перейдите в папку бота:

```bash
cd vk-bot
```

2. Установите зависимости:

```bash
npm install
```

3. Скопируйте файл конфигурации:

```bash
cp .env.example .env
```

4. Заполните `.env` своими значениями:

- `BOT_TOKEN` — токен VK бота
- `MONGODB_URI` — строка подключения к MongoDB
- `ADMIN_IDS` — список admin_id через запятую
- `VK_BOT_LINK` — ссылка на бот для сайта

## Запуск локально

```bash
npm start
```

## Команды VK-бота

- `/start` — начать оформление заказа
- `Оформить заказ в VK` — кнопка для запуска заказа
- `/orders` — получить список последних заказов (только для админов)
- `/order <id>` — получить детали конкретного заказа (только для админов)

## Структура проекта

- `index.js` — точка запуска приложения
- `bot.js` — логика диалога VK-бота
- `models/Order.js` — схема заказов Mongoose
- `config/db.js` — подключение к MongoDB
- `logger.js` — логирование через Winston

## Деплой на сервер

1. Загрузите папку `vk-bot` на сервер.
2. Установите Node.js 18+.
3. Скопируйте `.env.example` в `.env` и заполните.
4. Установите зависимости: `npm install`.
5. Запустите `npm start` или настройте процесс через PM2/systemd.
